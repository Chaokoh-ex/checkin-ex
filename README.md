# ระบบเช็คชื่อผู้เข้าอบรม

หน้าเว็บสำหรับเช็คชื่อผู้เข้าอบรม ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ทุกครั้งที่ติ๊กชื่อ ระบบจะบันทึกวันที่ ช่วงเวลา และเวลาลง Google Sheet ทันที

- หน้าเว็บ (`index.html`) วางบน **GitHub Pages**
- ข้อมูลเก็บใน **Google Sheet** โดยมี **Google Apps Script** (`apps-script/Code.gs`) เป็น API คอยรับ-ส่งข้อมูล

```
GitHub Pages (index.html)  ──fetch──▶  Apps Script Web app (/exec)  ──▶  Google Sheet
```

## ความสามารถ

- ติ๊กชื่อในเช็คลิสต์เพื่อเช็คชื่อ บันทึกเวลาลง Google Sheet ทันที ถ้าติ๊กผิดเอาติ๊กออกหรือกด "เลิกทำ" ได้
- แยกช่วง **เช้า / บ่าย** และเลือกวันที่ได้ (อบรมหลายวันก็ใช้ได้)
- ปุ่ม **"คนที่ยังไม่มา"** เปิด popup สีเหลือง แสดงรายชื่อคนที่ยังไม่มาแยกตามเพศ ติ๊กคนที่มาสายได้ และกดบันทึก "ขาด" ลงชีตได้
- **สรุปแยกตามเพศ** ทั้งบนหน้าเว็บและในชีต "สรุป"
- ดึงรายชื่อจากชีตคำตอบ **Google Form** ให้อัตโนมัติ แตกผู้สมัครคนที่ 2–5 เป็นรายคน ข้ามชื่อซ้ำ และดูเพศจากคำนำหน้า
- เพิ่มรายชื่อจากหน้าเว็บได้ (ทีละคน หรือวางจาก Excel ทีละหลายคน) หรือพิมพ์ลงชีต "รายชื่อ" ก็ได้
- หน้าเว็บโหลดข้อมูลใหม่ทุก 30 วินาที ให้เจ้าหน้าที่หลายเครื่องเห็นตรงกัน

## เวอร์ชัน

ป้าย `v1.1.0` ที่หัวเว็บและแถบท้ายเว็บบอกเวอร์ชันที่กำลังใช้ กดแล้วจะเห็นรายการ "มีอะไรใหม่" ของแต่ละเวอร์ชัน
ท้ายเว็บยังแสดงรหัส commit ล่าสุดบน GitHub ด้วย ถ้ารหัสนี้ตรงกับหน้า repo แปลว่าเปิดเวอร์ชันล่าสุดอยู่

ทุกครั้งที่แก้แล้วจะอัปขึ้น GitHub ให้แก้ด้านบนของ `<script>` ใน `index.html`:

1. เปลี่ยน `APP_VERSION` (แก้บั๊กเล็กน้อย `1.1.0 → 1.1.1` · เพิ่มความสามารถใหม่ `1.1.0 → 1.2.0` · เปลี่ยนใหญ่ `→ 2.0.0`)
2. เพิ่มรายการใหม่ไว้บนสุดของ `CHANGELOG` พร้อมวันที่และสิ่งที่เปลี่ยน
3. คัดลอก `index.html` ทับ `apps-script/Index.html` ให้สองไฟล์ตรงกัน

GitHub Pages ใช้เวลาประมาณ 1–2 นาทีหลัง push ถ้ายังเห็นเลขเก่า ให้กดรีเฟรชแบบล้างแคช (Ctrl+Shift+R)

## โครงสร้างไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บ (ขึ้น GitHub Pages) |
| `config.js` | ใส่ลิงก์ API ของ Apps Script (`API_URL`) |
| `apps-script/Code.gs` | โค้ดฝั่ง Google Sheet นำไปวางใน Apps Script |
| `apps-script/Index.html` | สำเนาหน้าเว็บ ใช้เมื่ออยากเปิดเว็บผ่านลิงก์ Apps Script โดยตรง (ไม่บังคับ) |
| `apps-script/appsscript.json` | ค่าโปรเจกต์ Apps Script (เขตเวลา สิทธิ์ Web app) ใช้กับเครื่องมือ clasp (ไม่บังคับ) |
| `.gitignore` | กันไม่ให้ไฟล์รายชื่อ (`.xlsx` `.csv`) หลุดขึ้น GitHub |
| `.nojekyll` | ให้ GitHub Pages เสิร์ฟไฟล์ตามที่เป็น |

## ขั้นตอนติดตั้ง

### 1. ฝั่ง Google Sheet

1. เปิด Google Sheet ที่เก็บคำตอบจาก Google Form ลงทะเบียน (ชีตชื่อ `การตอบแบบฟอร์ม 1`)
   ถ้ามีเฉพาะไฟล์ Excel ให้นำเข้าด้วย **ไฟล์ → นำเข้า → แทรกชีตใหม่** แล้วตั้งชื่อชีตเป็น `การตอบแบบฟอร์ม 1`
2. ไปที่ **ส่วนขยาย → Apps Script** แล้ววางเนื้อหา `apps-script/Code.gs` ทับไฟล์ `Code.gs` เดิม จากนั้นกดบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** และกดอนุญาตสิทธิ์
   ระบบจะสร้างชีต `รายชื่อ` `บันทึกเช็คชื่อ` `สรุป` `ตั้งค่า` ให้เอง
4. แก้ชีต `ตั้งค่า` ใส่ชื่อการอบรมและสถานที่ (ถ้าชีตคำตอบฟอร์มใช้ชื่ออื่น ให้แก้ที่ช่อง `ชีตแบบฟอร์ม`)
5. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (ต้องเลือกตัวนี้ หน้าเว็บบน GitHub จึงเรียก API ได้)
6. คัดลอก URL ของเว็บแอปที่ลงท้ายด้วย `/exec`
7. (ไม่บังคับ) ไปที่ **การตั้งค่าโปรเจกต์ → คุณสมบัติของสคริปต์** แล้วเพิ่ม `API_KEY` เป็นข้อความที่ตั้งเอง

> แก้ `Code.gs` ภายหลังเมื่อไร ต้องไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ทุกครั้ง ลิงก์ `/exec` จะยังเป็นอันเดิม

### 2. ฝั่ง GitHub

1. เปิด `config.js` แล้วใส่ URL จากข้อ 6
   ```js
   window.CHECKIN_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
     API_KEY: ''   // ใส่ให้ตรงกับข้อ 7 ถ้าตั้งไว้
   };
   ```
2. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. ไปที่ **Settings → Pages → Build and deployment → Source: Deploy from a branch** แล้วเลือก `main` และ `/ (root)` จากนั้นกด Save
4. รอประมาณ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/` เปิดได้ทั้งบนมือถือและคอมพิวเตอร์

### ทางเลือก: ไม่ใช้ GitHub

ถ้าในโปรเจกต์ Apps Script มีไฟล์ HTML ชื่อ `Index` (วาง `apps-script/Index.html`) ลิงก์ `/exec` จะเปิดหน้าเว็บได้เลย โดยไม่ต้องใช้ GitHub และไม่ต้องแก้ `config.js`

## ข้อมูลใน Google Sheet

**รายชื่อ**: `รหัส | คำนำหน้า | ชื่อ-นามสกุล | เพศ | หน่วยงาน | ตำแหน่ง | วันที่เพิ่ม | ที่มา`
- ถ้าพิมพ์ชื่อลงชีตเอง เว้นรหัสกับเพศว่างได้ ระบบจะเติมให้เอง (เพศดูจากคำนำหน้า)
- ถ้าลบแถวที่ดึงมาจากฟอร์มออก ระบบจะไม่ดึงกลับมาอีก (ระบบจำแถวฟอร์มที่นำเข้าไปแล้ว)

**บันทึกเช็คชื่อ**: `วันที่ | ช่วง | เวลา | รหัส | คำนำหน้า | ชื่อ-นามสกุล | เพศ | หน่วยงาน | ตำแหน่ง | สถานะ | บันทึกเมื่อ`
- สถานะ `มา` = ติ๊กเช็คชื่อแล้ว / `ขาด` = บันทึกจาก popup สีเหลือง (แถวสีเหลือง)
- ถ้าคนที่บันทึกว่าขาดมาสายแล้วถูกติ๊ก แถว "ขาด" จะถูกเปลี่ยนเป็น "มา"

**สรุป**: เปลี่ยนวันที่ (B2) หรือช่วง (B3) แล้วตารางชาย / หญิง / ไม่ระบุ จะคำนวณใหม่เอง

เมนู **ระบบเช็คชื่อ** ในชีตมีคำสั่ง "สร้างชีตเริ่มต้น" และ "ดึงรายชื่อจากแบบฟอร์มทั้งหมดอีกครั้ง"

## API (สำหรับนักพัฒนา)

| คำขอ | ตัวอย่าง |
|---|---|
| `GET  /exec?action=getData&date=2026-11-14&key=` | ดึงรายชื่อ และสถานะของวันนั้นทั้งช่วงเช้าและบ่าย |
| `POST /exec` body `{"action":"checkIn","args":["P0001","2026-11-14","เช้า"],"key":""}` | เช็คชื่อ |
| `POST` action `undoCheckIn` args `[id, date, ช่วง]` | ยกเลิกการเช็คชื่อ |
| `POST` action `markAbsent` args `[[id,...], date, ช่วง]` | บันทึกขาด |
| `POST` action `addPeople` args `[[{pre,name,sex,dept,pos}, ...]]` | เพิ่มรายชื่อ |

ทุกคำตอบอยู่ในรูป `{"ok": true, "data": ...}` หรือ `{"ok": false, "error": "..."}`
คำขอ POST ส่งแบบ `Content-Type: text/plain` เพื่อเลี่ยง CORS preflight ซึ่ง Apps Script ไม่รองรับ

## โหมดตัวอย่าง

ถ้า `API_URL` ยังว่าง หน้าเว็บจะเปิดเป็นโหมดตัวอย่าง ใช้รายชื่อสมมติ 12 คน และไม่บันทึกข้อมูลจริง ใช้ดูหน้าตาก่อนเชื่อมต่อได้

## ความเป็นส่วนตัวและความปลอดภัย

- **ห้ามอัปโหลดไฟล์รายชื่อผู้สมัคร** (`.xlsx` `.csv`) ขึ้น GitHub ไฟล์ `.gitignore` กันไว้ให้แล้ว รายชื่อจริงควรอยู่ใน Google Sheet เท่านั้น
- ใครที่มีลิงก์เว็บหรือลิงก์ API จะเห็นรายชื่อ (ชื่อ หน่วยงาน ตำแหน่ง) และติ๊กเช็คชื่อได้ ควรส่งลิงก์ให้เฉพาะเจ้าหน้าที่
- เบอร์โทร อีเมล และ LINE ID ในฟอร์มลงทะเบียน **ไม่ถูกส่งออกทาง API**
- `API_KEY` ช่วยกันคนสุ่มยิง API ได้ระดับหนึ่ง แต่ไม่ใช่รหัสลับ เพราะใครเปิดเว็บก็อ่าน `config.js` ได้
- GitHub Pages แบบฟรีใช้ได้กับ repository สาธารณะเท่านั้น โค้ดจึงเปิดให้คนอื่นเห็นได้ (แต่ไม่มีข้อมูลผู้เข้าอบรมอยู่ในโค้ด)
- จบการอบรมแล้ว แนะนำให้ปิดเว็บแอปที่ **จัดการการทำให้ใช้งานได้ → เก็บถาวร**
